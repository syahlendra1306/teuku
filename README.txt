TEUKU NEXSORA - WEBSITE MULTI-PAGE

Cara upload:
1. Ekstrak file ZIP.
2. Upload semua isi folder ini ke root repository GitHub (bukan hanya folder ZIP).
3. Pastikan index.html berada di root repository.
4. Buka Settings > Pages.
5. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.

File:
- index.html       : Beranda
- about.html       : Tentang Saya
- minat.html       : Bidang Minat
- keahlian.html    : Keahlian
- portfolio.html   : Portofolio
- perjalanan.html  : Perjalanan
- galeri.html      : Galeri
- kontak.html      : Kontak
- style.css        : Desain seluruh halaman
- script.js        : Menu, tema, dan jam WIB
